# Рандом на вечер

Сайт-рулетка, которая случайно выбирает фильм, игру или сериал. Чистый HTML + CSS + JavaScript, без сборки, без npm и без сторонних библиотек. Всё нужное лежит в этой папке, включая шрифты, — интернет для запуска не требуется.

## Как запустить

**Способ 1 — просто открыть файл.** Двойной клик по `index.html`. Сайт полностью работает и так.

**Способ 2 — локальный сервер** (удобно, если в приложении для кода нужен адрес вида `http://localhost`):

- Windows: двойной клик по `start.bat`
- macOS / Linux: `./start.sh`
- вручную: `python -m http.server 5173` и открыть <http://127.0.0.1:5173>


## Что внутри

- Режимы: Всё / Фильмы / Игры / Сериалы, жанровые фильтры подстраиваются под тип.
- Рулетка с анимацией ~0,9 с; запуск кнопкой или клавишей `Space`.
- «Без повторов» — последние 10 находок не выпадают снова.
- Избранное и история (10 последних) хранятся в `localStorage`, переживают перезагрузку страницы.
- Ссылки «Найти, где посмотреть»: Кинопоиск для фильмов и сериалов, Steam для игр.
- Постеры рисуются градиентами на CSS — картинок в проекте нет, папка весит копейки.
- Адаптив до 380 px и поддержка `prefers-reduced-motion`.

## Как добавить свой тайтл

Откройте `data.js`. Каждая запись — массив из семи полей:

```js
["Название", 2023, "movie", ["драма", "триллер"], 8.1, "Короткое описание.", "2 ч 12 мин"]
```

- тип: `"movie"`, `"game"` или `"series"`;
- жанры — массив строк, по ним строятся чипы фильтров;
- рейтинг — число (для игр и сериалов тоже используется);
- последнее поле — метаданные: длительность, платформа, число сезонов.

## Что легко поменять

- **Цвета и акценты** — переменные в начале `styles.css` (`--bg`, `--accent` и блоки `body[data-kind="movie|game|series"]`).
- **Скорость рулетки** — `setTimeout(tick, 60)` и интервалы внутри `spin()` в `app.js`.
- **Размер истории и списка «без повторов»** — `slice(0, 10)` в `app.js` (история и недавние находки).
- **Тексты** — прямо в `index.html`.

## Заметки

- Аккаунтов, API-ключей и внешних запросов нет: всё считается в браузере.
- База собрана вручную и лежит в `data.js` — её можно расширять до бесконечности.
- Сайт статический, поэтому его можно выложить на любой хостинг статики или открыть локально.
